VMware 扩展Ubuntu虚拟机硬盘大小

今天在创建Kubernetes Pods的时候发现调度失败，查看Pod Logs后发现是节点磁盘空间不足。

1

kubectl describe pods <pod-name> -n <namespace>
1

2 node(s) had untolerated taint {node.kubernetes.io/disk-pressure: }

我的Kubernetes集群两个Work Node的硬盘设置为20G。需要扩容到40G。 以下为在VMware虚拟机中扩容硬盘完整步骤：

Step1、在VMware中扩容虚拟硬盘

首先需要关闭正在运行的虚拟机。然后选中虚拟机，右键选择设置 -> 硬盘。 点击扩展（如果扩展按钮不能点击，检查是否有快照，一定要删除快照），输入目标大小(如20GB -> 40GB) 最后，重启虚拟机。

从上面信息可以看出sda已经显示40G了，但是分区sda3才18G。挂在的虚拟盘ubuntu--vg-ubuntu--lv才10G。所以需要扩展分区。

使用命令lvextend扩展逻辑卷(LV)

1
2
3
4

# 增加10G
sudo lvextend -L +10G /dev/mapper/ubuntu--vg-ubuntu--lv
# 增加所有剩余空闲大小
sudo lvextend -l +100%FREE /dev/mapper/ubuntu--vg-ubuntu--lv
1
2
3

ubuntu@node2:~$ sudo lvextend -l +100%FREE /dev/mapper/ubuntu--vg-ubuntu--lv

  Logical volume ubuntu-vg/ubuntu-lv successfully resized.

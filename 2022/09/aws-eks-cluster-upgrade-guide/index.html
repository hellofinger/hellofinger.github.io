由于 Amazon EKS 运行高度可用的控制平面，因此，一次操作只能升级一个次要版本，如需升级多个版本，请按版本顺序做多次升级操作。

Amazon EKS集群升级操作：

  • 17 版本升级至1.18版本；

  • 18 版本升级至1.19版本；

  • 19 版本升级至1.20版本；

本升级指南前置条件：

使用terraform module( https://github.com/terraform-aws-modules/terraform-aws-eks )创建的EKS集群。

module "eks" {
  source       = "terraform-aws-modules/eks/aws"
  cluster_name = "${var.cluster_name}"
  # 1.17 => 1.18
  cluster_version  = "1.18" 
}

# 修改terraform文件后，执行apply，等待集群更新完成

terraform apply

# Kube Proxy
# https://docs.aws.amazon.com/zh_cn/eks/latest/userguide/managing-kube-proxy.html#updating-kube-proxy-add-on
# 查询当前的版本
kubectl get daemonset kube-proxy --namespace kube-system -o=jsonpath='{$.spec.template.spec.containers[:1].image}'

# 更新目标版本
kubectl set image daemonset.apps/kube-proxy \
     -n kube-system \
     kube-proxy=602401143452.dkr.ecr.ap-southeast-1.amazonaws.com/eks/kube-proxy:v1.18.8-eksbuild.1

# CoreDNS

kubectl set image --namespace kube-system deployment.apps/coredns \
    coredns=602401143452.dkr.ecr.ap-southeast-1.amazonaws.com/eks/coredns:v1.7.0-eksbuild.1

# CNI
# https://docs.aws.amazon.com/zh_cn/eks/latest/userguide/managing-vpc-cni.html
# 查询当前版本
kubectl describe daemonset aws-node --namespace kube-system | grep Image | cut -d "/" -f 2

# 下载CNI组件
curl -o aws-k8s-cni.yaml https://raw.githubusercontent.com/aws/amazon-vpc-cni-k8s/release-1.7/config/v1.7/aws-k8s-cni.yaml

# 应用到集群
kubectl apply -f aws-k8s-cni.yaml
